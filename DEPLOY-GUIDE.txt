AKSHAR CAR SPA — WEBSITE DEPLOY GUIDE (Hindi/English)
=====================================================
Ye folder hi poori website hai. Koi software install nahi chahiye.

OPTION 1 — NETLIFY (Free, 5 minute) — RECOMMENDED
-------------------------------------------------
1. netlify.com par free account banao (Google se login).
2. "Sites" page par is ZIP ko unzip karke poora FOLDER drag-and-drop karo.
   (Yaad rahe: index.html folder ke andar top level par hona chahiye.)
3. Site live! Free link milega jaise: akshar-car-spa.netlify.app
4. Client ka domain (aksharcarspa.com) hai to: Site settings > Domain management
   me domain add karo — Netlify DNS steps de dega.

OPTION 2 — HOSTINGER / cPANEL SHARED HOSTING
---------------------------------------------
1. cPanel > File Manager > public_html kholo.
2. Is folder ki SARI files + folders (index.html, css, js, images, manifest.json)
   public_html me upload karo (ZIP upload karke Extract karna sabse easy).
3. Domain already connect hoga — site turant live.

OPTION 3 — VERCEL (Free, Netlify jaisa)
----------------------------------------
1. vercel.com par login > Add New > Project > is folder ko drag-drop karo.
2. Deploy dabao — live link mil jayega.
